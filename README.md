# IRONSIGHT — OSINT Dashboard (Fork)

A real-time OSINT command center for monitoring active conflicts. This is a fork of the original [NoblerWorks-HQ/IRONSIGHT](https://github.com/NoblerWorks-HQ/IRONSIGHT) project.

## 🎯 Why I forked this
I wanted a practical OSINT tool to monitor geopolitical events and improve my skills in modern web development. This fork allows me to experiment with new data sources, customize the UI, and learn how a real-time dashboard is built with Next.js.

✨ Features
- **Conflict Toggle** — Switch between Iran/Israel and Russia/Ukraine theaters.
- **Live Intel Feed** — Aggregated news with relevance filtering.
- **Telegram OSINT** — Public channel scraping with auto-translation.
- **Theater Map** — Interactive Leaflet map with aircraft, naval vessels, strikes, and missile trajectories.
- **Air-Raid Alerts** — Real-time sirens for both theaters.
- **Markets & Crypto** — Live defense stocks, oil, gold, and cryptocurrency prices.
- **Prediction Markets** — Polymarket odds relevant to the selected conflict.
- **Satellite Thermal Detect** — NASA FIRMS fire/explosion data.

🛠 Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Maps:** Leaflet / React-Leaflet
- **Deployment:** Vercel

🚀 Getting Started

 Prerequisites
- Node.js 22 or later
- npm or yarn

 Local Development
```bash
git clone https://github.com/amir000pq/IRONSIGHT.git
cd IRONSIGHT
npm install
npm run dev
Open http://localhost:3000 in your browser.

📊 Data Sources
All data comes from free, publicly accessible endpoints. No API keys required. See the original project's Data Sources section for a full list.
